# Week 4 导读：优先股、可转债与条款的保护

## 本周定位

上一周你学会了用格雷厄姆的四原则给债券"体检"，结尾我们预告了固定价值家族里两个"债不像债"的成员。这一周就把它们请上场：先看**优先股**——拿着固定股息、却没有任何硬手段强制兑现的尴尬品种，格雷厄姆为什么把它叫作"最不利的组合"；再翻**借钱合同里的护栏**（防护条款），看清"条款写在纸上是弱保护，写在能力里才是强保护"；然后是本周的主角**可转债**——一张能变身成股票的借条，我们用手算拆开它的"跌有底、涨跟涨"；接着识别那些**名不副实**的证券（收益债券、担保证券），学会"名字会骗人，条款和企业不会"；最后补上投资闭环的最后一块拼图：**买完不是结束**——持有期的持续检查与卖出纪律。收尾用一整章实战，把 A股可转债的四大条款（转股价/下修/强赎/回售）逐条读懂。

## 学完你会得到什么

- 看懂一家公司的**资本结构三层楼**：债券、优先股、普通股各站在哪一级台阶，为什么优先股"债不像债、股不像股"；
- 会读借钱合同里的**护栏清单**（限制新增债务、营运资本、偿债基金），并且知道这些护栏什么时候失灵；
- 会手算可转债的**转换比率、转换价值、转换平价、转换溢价**，看懂"债券底价 + 转换价值"的价值地图；
- 能一眼识破**名不副实**的证券：收益债券、含糊的担保、"积累股息"的幻觉；
- 建立持有的**复检与卖出纪律**（买入理由消失 = 卖出信号），并读完一份 A股可转债的募集说明书条款。

## 本周术语表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 优先股 | preferred stock | 股息固定、清算时排在普通股前面，但没有到期日、也强制不了分红的"混血证券" |
| 累积条款 | cumulative | 今年欠的优先股息滚到明年，没补齐前普通股不得分红 |
| 防护条款 | protective covenants | 写进债券契约或公司章程的护栏：限制新增债务、维持营运资本、强制还本等 |
| 偿债基金 | sinking fund | 发行人每年定期掏钱收回一部分债券，边借边还 |
| 可转换债券 | convertible bond | 附带"按约定价格换成股票"权利的债券：跌有底、涨跟涨 |
| 转换价值 | conversion value | 一张转债按转换比率换成立刻卖掉的股票值多少钱 |
| 转换溢价 | conversion premium | 转债市价高出转换价值的部分：为期权支付的价格 |
| 收益债券 | income bond | 利息"赚到了才付"的债券——戴着债券帽子的优先股 |
| 担保证券 | guaranteed security | 由另一家公司担保本息的证券；价值取决于担保人的实力 |
| 下修（转股价向下修正） | downward revision of conversion price | A股转债特有条款：正股持续走低时，公司可调低转股价，把"换股券"重新变值钱 |
| 强赎（强制赎回） | issuer call / redemption | 正股涨到约定水平时，公司有权按面值加利息把转债买回去——逼你转股 |
