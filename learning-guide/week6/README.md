# Week 6 导读：利润表分析 I——看穿数字的游戏

**本周定位：** Week 2 教会你"读"利润表——体检报告怎么翻；本周教你"审"利润表——像法医一样，每一行都问一句"这里能藏东西吗"。因为 Week 5 已经确立：股票的价值锚是盈利能力，而盈利能力的原材料就是利润。**利润如果被化妆，后面所有估值都是在给照片量身高。** 原书 Part V 开头三章（第 31、32、33 章）是全书"侦探味"最浓的部分：1930 年代真实的数字魔术，一件件摆上解剖台。

## 🎯 学完你会得到什么

1. **一双法医的眼睛**：拿到任何一张 A股/港股 利润表，你会按"8 行安检表"逐行过一遍，知道每一行的高发问题和去哪查附注；
2. **本周第一把刀**：非经常性损益的辨认与剔除——你会正确使用"扣非净利润"，并识破"年年异常"的一次性项目；
3. **三套魔术的鉴定能力**：不对称记账、无形资产吹气、子公司暗账——原书 1930 年代原案 + 它们今天的变体；
4. **一条铁律**：会计可疑的公司，所有证券一律回避——品格没有折扣率；
5. **一张随身清单**：利润表分析四问（成色 / 口径 / 现金 / 可信），为 Week 7 的"平均盈利能力"备好原材料。

## 本周术语表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 非经常性损益 | non-recurring items | 与主业无关或不会定期再发生的一次性损益，要从"常态利润"里剔出去 |
| 扣非净利润 | net profit after non-recurring items | A股 披露口径：剔除非经常性损益后的归母净利润，估值优先用它 |
| 盈余 | surplus | 历年留下、没分掉的利润池子，绕过利润表直接加水放水——魔术的后门 |
| 储备 / 准备金 | reserves | 为未来损失预提的钱，计多计少都能调节利润 |
| 盈利能力 | earning power | 假设当前经营延续，公司年复一年能赚到的平均数（估值的锚） |
| 制造利润 / 洗大澡 | manufactured earnings / big bath | 超额减记砸低资产基数，让以后年份的利润"凭空"变好 |
| 合并报表 | consolidated statements | 把母子公司当成一家整体来出报表；没并进来的子公司是暗账高发区 |
| 少数股东损益 | minority interest | 非全资子公司的利润里不属于母公司股东的那块；估值用归母口径 |
| 归母净利润 | net profit attributable to parent | 净利润扣掉少数股东份额后，真正属于上市公司股东的部分 |
| 归母口径之外的验钞机 | income-tax check | 用应交税金倒推税前利润，与报给股东的利润对照——差距离谱要追问 |
