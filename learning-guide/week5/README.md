# Week 5：普通股投资理论——股票是公司的一部分

## 本周定位

前三周我们一直站在债主的位置上（[Week 3 债券](../week3/README.md)、[Week 4 优先股与可转债](../week4/README.md)）；本周换到桌子的另一边，坐上老板的位置，回答全书最核心的一次观念转身：**股票不是筹码，是企业所有权的一份子**——并由此搭起普通股估值的骨架（两个锚）与第一个现实修正器（股息）。

## 学完你会得到什么

- 能向别人讲清楚："买股票 = 买公司的一部分"这条常识是如何在血泪中挣来的，以及它对估值方法的全部含义；
- 拿到全课程估值的骨架——**盈利能力锚 + 资产价值锚**，知道 Week 7 / Week 8 / Week 9 分别在这张地图的哪个位置上施工；
- 对"为增长支付高价"产生生理性警觉，能用"两颗雷"和"三重风险"识别每一场新时代行情（1999 / 2015 / 2021 剧本通用）；
- 会算**股息率、盈利收益率、派息率**，能拆解茅台（高分红率）、腾讯（回购 + 分红）、中国石油（周期分红）三种股东回报性格；
- 建立 A 股 / 港股股息税的税后意识，并拿到"买股票 = 买公司"检查清单 v1。

## 本周术语表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 掺水股 | watered stock | 面值背后没有对应真实资产投入的股票——往牛肚子里灌的水 |
| 新时代理论 | new-era theory | "价值全看未来盈利、股息与资产无关紧要"的 1920 年代教义，1929 年破产 |
| 盈利能力 | earning power | 假设当前经营延续，未来一段时期平均每年能赚到的钱 |
| 账面价值 | book value | 每股对应的净资产，"账本上的家底" |
| 流动资产价值 | current asset value（net-net） | 流动资产减去全部负债的最保守估值口径，Week 8 展开 |
| 股息 / 股息率 | dividend / dividend yield | 公司派给股东的现金；股息率 = 每股股息 除以 每股股价 |
| 盈利收益率 | earnings yield | 每股盈利 除以 每股股价，市盈率的倒数 |
| 派息率 | payout ratio | 股息 占 盈利的比例，衡量公司"舍不舍得"分 |
| 回购 | share buyback | 公司买回自家股票并注销，变相的现金回报 |
| 自由现金流 | free cash flow | 公司维持生意正常运转后真正多出来的现金，一切股东回报的源头 |
