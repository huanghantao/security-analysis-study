# Week 7 导读：利润表分析 II——盈利能力与市盈率

**本周定位：** 上一周（[Week 6](../week6/README.md)）你学会了"审"利润表：剔非经常、查口径、验现金，把一年的利润**洗干净**。但 Week 5 第 2 章早就说了：估值的原料不是某一年的利润，而是**盈利能力（earning power）**——多年平均、可持续的那种赚法。本周干两件事：**把洗干净的单年利润加工成多年的盈利能力**，然后**给这台赚钱机器装上两把尺**——市盈率（价格尺）和资本结构（杠杆尺），最后拿贵州茅台从头到尾算一遍。原书第 34、37-40 章是全书"从利润走向估值"的枢纽：第 37 章开篇那句"研究过去的唯一实际用途，是它可能为未来提供线索"，值得抄下来贴在书桌上。

## 🎯 学完你会得到什么

1. **一台"盈利能力加工机"**：把任何一家 A股/港股 公司的多年利润，按"剔非经常（Week 6）→ 验折旧（本周第 0 章）→ 取平均（第 1 章）"三步，加工成一个站得住的年均盈利数；
2. **一双识破"折旧魔术"的眼睛**：计提不足、重估基数、藏进盈余——1930 年代真实案例 + 今天还能见到的变体；
3. **一把带刻度的尺**：市盈率的正确用法与三大陷阱（周期顶部低 PE、口径不一致、股本稀释），以及格雷厄姆"20 倍平均盈利"上限的来龙去脉；
4. **一个杠杆透视镜**：两家同利润的公司，借钱多少如何让股东回报天差地别；什么时候杠杆是甜点，什么时候是悬崖；
5. **一份完整的实战流程**：给茅台手算市盈率的全过程——以后你可以把同一套算式套到任何一家公司上。

## 本周术语表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 折旧 | depreciation | 固定资产随使用与岁月贬值的会计表达——机器会老，账要认 |
| 直线折旧 | straight-line depreciation | 成本平均分摊到使用年限：5 万用 5 年，每年提 1 万 |
| 摊销 | amortization | 折旧的统称外延：租赁权、专利、无形资产的价值分期计入费用 |
| 折耗 | depletion | 矿藏、油气等自然资源被开采消耗的折旧表亲 |
| 盈利能力 | earning power | 假设当前经营延续，未来平均每年能赚到的钱（Week 5 的估值锚） |
| 每股收益 | earnings per share (EPS) | 归母净利润 ÷ 总股本：每一股分到的利润 |
| 市盈率 | price-earnings ratio (P/E) | 股价 ÷ 每股收益：为 1 元盈利付几块钱 |
| 稀释 | dilution | 可转债转股、期权行权等让股本变大、每股盈利变薄 |
| 资本结构 | capitalization structure | 公司的钱里债、优先股、普通股各占多少 |
| 杠杆 | leverage / trading on the equity | 用借来的钱放大股东回报——利润好时放大收益，差时放大亏损 |
| 利息保障倍数 | interest coverage | 息前利润 ÷ 利息：赚的钱够付几次利息（Week 3 的老朋友） |
