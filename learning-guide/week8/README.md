# Week 8：资产负债表分析——账面价值与清算价值

## 本周定位

[Week 5 第 2 章](../week5/02-股票的价值从哪里来.md)给了一副估值骨架：**盈利能力锚 + 资产价值锚**；[Week 7](../week7/README.md) 把第一只锚（盈利能力锚）拆到了底，本周轮到第二只锚下水——**资产锚**。我们要做两件事：一是给"这份家底值多少"算账，从账面价值一路算到最极端的清算价值；二是回答一个更刁钻的问题——**为什么股票会卖得比"散伙价"还低，而且一卖好多年**。前者是技术，后者牵出全书的另一条暗线：股东的权利。

## 学完你会得到什么

- 会算**每股净资产**和**市净率 PB**，并且知道 PB 的分母（账面价值）和分子（市值）各自藏了什么水分；
- 掌握一条从宽到严的估值阶梯：账面价值 → **流动资产价值（net-net）** → 现金资产价值，能拿计算器亲手算出一家公司的"散伙底价"；
- 背下清算估值第一规则——**负债足额扣，资产打折看**，并会用原书的清算折扣表做完整估算；
- 理解"价格长期低于清算价值"意味着什么：要么市场错了，要么公司该散伙——以及这条悖论背后的股东权利问题；
- 拿到一份破净股（PB < 1）的扫描地图和改良版烟蒂检查清单，知道 A股/港股 里哪些便宜能捡、哪些是陷阱。

## 本周术语表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 账面价值 | book value | 有形资产减去全部负债后归属股东的净资产 |
| 每股净资产 | book value per share | 账面价值 ÷ 总股本 |
| 市净率 | price-to-book ratio（PB） | 股价 ÷ 每股净资产；低于 1 叫"破净" |
| 有效面值 | effective par | 优先股票面金额与真实求偿差太远时，按真实求偿重算的扣除值 |
| 流动资产价值 | current-asset value | 只数流动资产、减去全部负债的极保守估值口径 |
| 净-净股 | net-net | 市价低于流动资产价值的股票——最经典的格雷厄姆烟蒂 |
| 现金资产价值 | cash-asset value | 只数现金及等价物、减去全部负债的最严口径 |
| 清算价值 | liquidating value | 把公司拆开变卖、还清全部债务后股东能拿回的钱 |
| 营运资本 | working capital | 流动资产 - 流动负债，衡量短期财务松紧 |
| 酸性测试比率 | acid-test ratio | （流动资产 - 存货）÷ 流动负债，不看存货的保守流动性体检 |
