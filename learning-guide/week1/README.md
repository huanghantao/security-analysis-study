# Week 1：出发前的地图——证券分析是什么、不是什么

> **本周定位：** 上场之前先看地图。这一周我们不碰任何报表、不背任何公式，只回答四个问题：
> 这本书是谁写的、凭什么被称为"价值投资圣经"？"投资"和"投机"到底差在哪？
> "价值"是什么、为什么它是个区间而不是一个数？以及——想查一家公司的底细，去哪里查？

## 📖 本周术语表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 证券 | security | 代表某种权利的凭证：借钱的凭据（债券）或公司所有权的一角（股票） |
| 债券 | bond | 借条：约定利息和还本日期，公司散伙时最先受偿 |
| 优先股 | preferred stock | 介于债与股之间：有约定股息、排在普通股前面，但没有还本日期 |
| 普通股 | common stock | 股票：分完利息、税和优先股之后剩下的都归你，风险最大、上限最高 |
| 投资 | investment | 格雷厄姆定义：经深入分析、承诺本金安全并获得满意回报的操作 |
| 投机 | speculation | 不满足上述要求的操作——尤其指把成败押在对未来的猜测上 |
| 内在价值 | intrinsic value | 被"资产、盈利、股息、确定远景"等事实支持的价值，是一个区间而非精确数字 |
| 安全边际 | margin of safety | 买入价低于价值区间的差额，为你估错值留出的缓冲垫 |
| 定量因素 | quantitative factors | 能查到数字的事实：财报数据、经营统计 |
| 定性因素 | qualitative factors | 难以量化的判断：行业性质、管理层、前景 |
| 信息披露 | disclosure | 公司依法向公众公开经营信息的义务和文件（年报、公告等） |
