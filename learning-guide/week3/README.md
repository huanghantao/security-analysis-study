# Week 3 导读：债券——借出去的钱怎么保本

## 本周定位

上一周你学会了读三张财务报表，又在数学小灶里练好了**复利与贴现**两把算尺。这一周我们第一次真正上手《证券分析》的正文：格雷厄姆把全书最重的笔墨之一给了债券，因为**"先学会不亏本金"是整个投资体系的入场券**。读完本周你会发现：所谓买债券，就是放一笔"回报写死在合同里"的贷款——而正因为回报封顶，分析的焦点只剩一件事：**别把钱借给还不起的人**。这套思路下周会继续延伸到优先股和可转债，往后还会一路迁移到股票估值里。

## 学完你会得到什么

- 看懂任何一张债券的基本信息：面值、票息、期限、价格、到期收益率各是什么、互相怎么换算；
- 掌握格雷厄姆选债四原则，以及"只有强公司才有强债券"这条硬纪律；
- 会算**利息保障倍数**并判断一家公司付息的底气够不够；
- 明白债券价格为什么天天变：利率与信用两个开关，一涨一跌都有逻辑；
- 拿到一份普通人可用的债券工具清单（A股/港股）和一张"格雷厄姆式买债检查清单"。

## 本周术语表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 债券 | bond | 一张可以转手的标准化借条：约定利息、到期还本 |
| 面值 | face value / par value | 借条上写的本金数额，到期按它还钱 |
| 票息 / 票面利率 | coupon / coupon rate | 每年固定支付的利息，利率 = 票息 ÷ 面值 |
| 到期日 | maturity | 归还本金的日期；期限就是距离到期日的时间 |
| 到期收益率 | yield to maturity (YTM) | 按当前买入价持有到期能拿到的年化回报，随价格变动 |
| 违约 | default | 发行人还不起利息或本金；信用风险的极端形式 |
| 信用评级 | credit rating | 评级机构给"还钱能力"打的分，从 AAA 一路排到垃圾级 |
| 利息保障倍数 | interest coverage ratio | 可用于付息的利润是利息费用的几倍，越大越安全 |
| 利率风险 | interest rate risk | 市场利率上行导致存量债券价格下跌的风险 |
| 久期 | duration | 衡量债券对利率变化敏感度的指标；期限越长越敏感 |
