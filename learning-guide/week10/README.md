# Week 10：大结业——完整分析一家公司

> **本周定位：** 最后一周，毕业周。前九周你攒下了一桌子零件——三张表、四问、五问、两把锚、
> 一位市场先生、一条安全边际——但零件不等于机器。这一周我们做两件事：
> **把九周串成一条五步流水线**，然后**挑一家真实公司（福耀玻璃）从头走到尾**，
> 一直走到那个最诚实的产出——一段价值区间和一个明确的判定。
> 课程在这里结束，分析从这里开始。

## 🎯 学完你会得到什么

- 一条**可重复的分析流水线**：五步法，每步有明确的问题、工具和产出——分析从"态度"变成"动作"；
- 一次**完整的实战示范**：从一句话生意描述到估值判定带，中间每个数字都标了出处和口径；
- 一本**可勾选的防错手册**：全书四周的清单汇成一册，外加估值纪律和心理纪律各 5 条；
- 一个**全球视角**：格雷厄姆的原则为什么能跨境使用，A港股里哪些"麻烦"其实是折价的来源；
- 一张**毕业后的路线图**：下一本读什么、真实数字去哪查、纸上组合怎么起步。

## 📖 本周术语表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 全球价值投资 | global value investing | 把格雷厄姆的原则用到母国之外的市场——原则不变，参数随市场调整 |
| 特许经营权 | business franchise | 一门生意"别人抢不走"的东西：品牌、客户认证、分销网络、成本优势 |
| 公司治理 | corporate governance | 管理层为谁工作的制度安排：董事会、投票权、披露规则与制衡机制 |
| 美国存托凭证 | ADR（American Depositary Receipt） | 外国公司股票在美股市场的代存凭据，交易便利，但股东权利可能缩水 |
| 参与证书 | participation certificate | 只有分红权、没有投票权的证券——Russo 买雀巢时被迫接受的形态 |
| 非合并子公司 | unconsolidated subsidiary | 没并进母公司报表的控股子公司——报表上看不见的利润与负债 |
| 汇率风险 | currency risk | 外币收入与资产随汇率波动带来的损益，海外生意躲不开 |
| 对冲 | hedge | 用反向头寸抵消某类风险（如汇率）；有成本，有时贵到不值得做 |
| 五步法 | five-step process | 本课总结的分析流水线：理解生意 → 读三表 → 调利润 → 双锚估值 → 安全边际与纪律 |
| 检查清单 | checklist | 把纪律写成可勾选的动作清单，防止情绪接管决策——防情绪，不是防蠢 |
