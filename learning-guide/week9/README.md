# Week 9：价格与价值——市场先生与安全边际

> **本周定位：** 前八周我们把"价值"这把尺子一点点造了出来（报表 → 利润 → 资产），
> 这一周回答那个从 Week 1 就悬着的问题：**价格为什么会偏离价值？偏离的时候，你该怎么办？**
> 这是全书情绪与哲学的高峰：你会见到投资史上最著名的角色——"市场先生"；
> 你也会等来整本《证券分析》真正的落点——安全边际（margin of safety）。
> Week 1 埋下的"价格 - 价值 - 安全边际"铁三角，本周第 3 章正式补完最后一角。

## 🎯 学完你会得到什么

- 一套**解释力极强的答案**：价格偏离价值，源头是群体心理的"夸大、简化、忽视"——贪婪期夸大未来，恐慌期忽视当下；
- 一个**受用终身的角色模型**：市场先生。他每天来报价，他的报价你可以利用、可以无视，唯独不该照单全收；
- 一道**分水岭式的判断**：预测价格（市场分析）和评估价值（证券分析）是两门手艺，后者自带安全边际，前者没有；
- 一块**整本书的落点**：安全边际在债券上是保障倍数、在股票上是价格折扣、在成长股上是保守假设——同一个思想的三种形态；
- 一份**能落地的极端时刻行动指南**：逆向操作的三个前提，和"PE/PB 分位数"一句话检测法。

## 📖 本周术语表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 市场先生 | Mr. Market | 格雷厄姆的比喻：一个每天来报价的情绪化合伙人，报价仅供你利用，不供你服从 |
| 安全边际 | margin of safety | 买入价与"保守评估的价值"之间的差额，为你估错值留出的容错空间 |
| 市场分析 | market analysis | 预测价格走势的手艺（择时、看图、算指标），格雷厄姆认为它没有安全边际 |
| 证券分析 | security analysis | 评估价值的手艺：判断价格与被事实支持的价值的关系 |
| 图表分析 | chart reading | 只研究过去价格走势来预测未来价格的方法，原书论证它"不可能是科学" |
| 二线股 | secondary issues | 非市场龙头、关注度低的公司股票，低估与错杀都更容易出现在这里 |
| 老练证券 | seasoned issue | 投资者久已熟悉的公司所发的证券，价格有"惯性"，跌得慢也可能撑得虚 |
| 新上市证券 | unseasoned issue | 新进入市场的证券，对坏消息极度敏感，容易跌过头 |
| 正常价值 | normal value | 用平均盈利乘以合理倍数估出的价值基准，机械择时方案用它当标尺 |
| 分位数 | percentile | 当前读数在自身历史区间里排第几位的刻度，本周的"偏离检测"工具 |
