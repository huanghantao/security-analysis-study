## 🤔 这门课和"自己啃原书"有什么区别？

《证券分析》是公认的"价值投资圣经"，也是公认的难读：80 年前的美国案例、金融术语铺天盖地、
一半篇幅在教你怎么读财报。这门课反过来为你做了四件事：

- **零基础补课**：Week 2 专门用一家"奶茶店"把三大财报教会你，之后原书的报表分析不再吓人（原书默认你会，我们不默认）；
- **翻译并拆解**：每章精选原书英文金句（附翻译和页码），帮你逐步过渡到啃英文原版；
- **时空转换**：原书的铁路债券、1930 年代案例全部标注"当年的背景"，并给出 A股/港股 的当代表达；
- **看图学习**：所有涉及精确比例、坐标、结构的图都是脚本生成的 PNG，不用会变形的 ASCII 图。

## 📖 怎么用这套教程

本教程就是本仓库，三个目录各司其职：

```
security-analysis-study/（仓库根）
├── learning-guide/   ← 教程正文（你正在看的）
├── figures/          ← 所有配图的生图脚本 + 生成好的图片（想改图就改脚本重跑）
├── scripts/          ← 检查工具（公式规范检查等）
└── CURRICULUM.md     ← 课程总纲（写作说明书，读者可略过）
```

1. **按顺序读，别跳。** 每周都依赖前面。
2. **边读边对照原书。** 每章末尾的「📖 回到原书」给出对应英文页码，鼓励读原文；
3. **每章做「✍️ 想一想」**。思考题只需要动脑，不需要代码；
4. **看图不爽？** 改 `figures/gen_*.py` 里的数字重新运行即可。

> 🖼️ 关于图片：所有涉及精确坐标的图都是**脚本生成的 PNG**（在 `figures/out/` 里）。
> 想调整任何一张图，改 `figures/` 里对应脚本重新运行即可。
